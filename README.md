# BOAT AI LAB — スマホ簡易起動版（PWA）

## できること
- スマホ画面に合わせた買い目記録フォーム
- 3連単・2連単・3連複の記録
- 1レース最大5,000円の入力上限
- オッズと手入力の推定確率による簡易期待回収率計算
- 結果入力、回収率・収支集計、CSV出力
- 一度読み込んだ後の簡易オフライン表示

## 注意
この版は**買い目を自動予想しません**。出走表・オッズ・結果の自動取得もありません。予想確率は利用者が入力します。実際の舟券購入や自動投票は行いません。データはブラウザのlocalStorageに保存され、同じ端末・同じブラウザでのみ利用できます。ブラウザデータ消去で記録が失われるので、CSVを定期的に保存してください。

## 最も簡単な公開方法（GitHub Pages）
PWAとしてホーム画面に追加するにはHTTPSのURLが必要です。
1. GitHubで新規リポジトリを作成。
2. `index.html`, `manifest.json`, `sw.js`, `icon.svg` をリポジトリのルートにアップロード。
3. リポジトリの **Settings → Pages** を開く。
4. Build and deploymentで **Deploy from a branch**、ブランチ `main`、フォルダ `/ (root)` を選んで保存。
5. 公開された `https://ユーザー名.github.io/リポジトリ名/` をiPhoneのSafariで開く。
6. Safariの共有ボタン → **ホーム画面に追加** → 必要に応じて「Webアプリとして開く」をオン → 追加。
7. AndroidではChromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ。

## 更新
GitHub上のファイルを更新すると公開版も更新されます。更新が反映されない場合はSafariでページを再読み込みするか、ホーム画面のアプリを閉じて開き直してください。
